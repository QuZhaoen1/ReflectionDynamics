# Qwen2.5-32B：E4 / E5 / E6 完整实验归档

完成时间：2026-11-09 02:13:30（北京时间）。对应任务 `t-20261105111418-w46lh`，以及此前可恢复的分阶段运行。代码起点为仓库 `e1c4829bac061ba3d7de39d413368efaf7e62ee6` 的 `ReflectionDynamics 2/`。

## 结论

当前结果不支持“CAVR 在各任务上普遍提高正确率”或“在线刷新训练稳定增强选择反思能力”的强结论。数学独立测试上反思仍会伤害正确答案；HumanEval 出现正向信号。标准 GRPO 的三个种子都表现出反思概率略降、损害率略降，但选择性提升并非三个种子一致。

这些负结果与正结果均保留，没有按测试分数挑选最佳轮次或修改已锁定的策略。

## E5 独立测试

下表为预先指定的 `cavr_online-round3`，成本系数 0.05，CAVR 与置信度规则均分配约 30% 的反思调用预算。

| 数据集 | 可解析草稿数 | 直接提交 | CAVR 30% | 同报告内置信度规则 30% |
|---|---:|---:|---:|---:|
| MATH | 9415 | 66.94% | 66.44% | 66.68% |
| AIME | 130 | 6.92% | 7.12% | 7.12% |
| GSM8K | 2632 | 88.64% | 86.91% | 86.83% |
| HumanEval | 256 | 75.78% | 80.00% | 78.93% |

**统计口径：**这是固定、可解析草稿上的模块化策略期望正确率，来自反思结果的重复采样；不是完整测试集端到端 pass@1。MATH 5000 题、AIME 90 题、GSM8K 1319 题、HumanEval 164 题，各生成两份 base 草稿，解析失败草稿未进入此表。所有执行模型使用相同草稿，故 commit 列相同不表示不同模型的独立作答能力相同。

置信度一列是 `cavr/report.json` 内的 `confidence@0.3` 策略；独立拟合的 confidence-only 控制器另在 `confidence/report.json`，不可混称。固定收益阈值策略 `cavr_threshold` 及所有预算/成本设置均在完整报告中，不能仅用这张预算表代表所有设置。

CAVR 相对 commit 的增量：MATH −0.50 个百分点，GSM8K −1.73，AIME +0.20，HumanEval +4.22。报告内区间按原题聚类，只条件于记录的生成样本，不包含训练种子或完整生成不确定性。AIME 样本较小；HumanEval 的改善不能单独证明在线训练是原因，需与 base、step400、no-refresh、uniform 等完整对照一起解释。

## E6 三个独立标准训练种子

统一使用 458 份固定验证草稿（295 道原题），各种子均从 base 开始。训练前后分别测量；基础模型被重复采样，故各次基线数值略有不同。

| 种子 | 反思概率：前→后 | 强制反思纠错率：前→后 | 强制反思损害率：前→后 | 选择性协方差：前→后 |
|---|---|---|---|---|
| 41 | 59.75%→58.25% | 15.63%→15.72% | 11.92%→11.44% | 0.01103→0.01087 |
| 73 | 59.82%→59.05% | 15.56%→16.13% | 11.30%→10.99% | 0.01114→0.01212 |
| 107 | 59.61%→59.36% | 15.81%→15.85% | 11.54%→11.08% | 0.01126→0.01160 |

组合动作选择概率 p 与强制反思净收益 u，计算 mean(p*u)，再比较训练前后：

| 种子 | 训练带来的模块化正确率增量 | 按题目聚类的 95% 区间 |
|---|---:|---:|
| 41 | +0.167 个百分点 | [−0.168, +0.493] |
| 73 | +0.345 个百分点 | [+0.005, +0.688] |
| 107 | +0.195 个百分点 | [−0.117, +0.535] |

三个点估计均为小幅正向；两个区间跨零，种子 73 下界仅略高于零。不应据此宣称显著、稳定的大幅改进。E6 是标准训练重复实验，**不是 E4 CAVR 方法的三个随机种子复现**。`selection.json` 的 `utility` 是 mean(u)，不能误读为 mean(p*u)；派生的前后对比见 `E6-before-after.json`。三个种子的粗粒度均值/标准差见 `reports/E6-independent-seeds.json`。

## 复现与实现限制

训练使用八卡 A100 80GB、BF16、TRL GRPO + DeepSpeed ZeRO-3；训练内未启用 vLLM。生成评估使用 vLLM 0.14.1、BF16、TP=1、8 个逻辑分片。固定隐藏特征另用 Transformers 提取。不得将这些 vLLM 结果和旧 HF 推理数据当作同一实现合并。

`reproduction/source/` 是实际运行实现的审计快照。读取 `reproduction/config.json`、`profile.yaml` 与 requirements；按本地部署替换 `${RUN_ROOT}`、`${LEGACY_ROOT}`、`${PROJECT_ROOT}`、`${PUBLIC_RUNTIME}`，准备原始模型/草稿/特征后重新初始化本地清单。它不是复制后直接执行的独立安装包，也不包含 32B 权重、优化器状态、原始题目、生成文本和隐藏特征。

所有公开快照均移除了账号存储路径。`config.sha256`、原始 receipt 等保留的是服务器原文件校验值；路径替换后的文件哈希可能不同，以 `archive-manifest.json` 的 `published_sha256` 校验公开快照。不要拿公开脱敏文件直接验证原始运行清单。

本轮修复包括短 IPC 路径、独立 vLLM 端口、策略锁 tuple/list 序列化、DeepSpeed 批量配置、训练专用 PEFT 兼容补丁，以及严格限定的执行器标识兼容性核对。后者仅允许审查过的非推理脚本差异；原始生成和控制器仍保持原标识，派生预测/报告保存转换审计。权重、运行库、采样、推理源码变化不会被静默放行。no-refresh 的真实执行器漂移仍显式标记。

HumanEval 使用任务内隔离的代码评分器；安全与 Docker 等价性检查随配置归档。批量 vLLM 延迟是摊销时间，不是用户逐题串行延迟。相同反思调用预算不等于相同总 FLOPs。
